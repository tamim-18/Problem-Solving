## 🚀 Getting Started

### Prerequisites
- **Java**: JDK 8 or higher for Java implementations
- **C++**: G++ compiler with C++11 support or higher
- **Python**: Python 3.6 or higher

### Running Solutions

#### Java Programs
```bash
cd "InterView Prep/Algorithm/Math"
javac NumberFunctions.java
java NumberFunctions
```

#### C++ Programs
```bash
cd "interview/tree/Binary Tree"
g++ -o solution 01_create_binary_tree_descriptions.cpp
./solution

python3 Number_of_pair_interchangable.py
```
